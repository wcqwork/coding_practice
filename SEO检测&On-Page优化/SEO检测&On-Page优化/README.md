本目录包含「增长引擎」技术 SEO 相关的产品原型与规则文档，可按以下方式查阅。

## 产品原型

在浏览器中打开 **`index.html`** 即可查看交互式产品原型（本地直接双击打开，或通过静态文件服务访问均可）。

## 功能逻辑说明

进入原型界面后，在**页面右上角**点击 **「功能逻辑说明」** 按钮，可打开侧栏查看本期功能的业务逻辑、交互说明与权限表述（产研内部说明，非客户可见正文）。
