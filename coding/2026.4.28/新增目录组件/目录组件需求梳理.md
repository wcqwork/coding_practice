# 目录组件需求梳理

## 1. 背景与目标

### 1.1 需求背景

- 来源：运营、客户反馈。
- 当前编辑器需要新增文章目录能力，用于自动提取页面正文中的标题结构，帮助前台访客快速定位内容章节。
- TAPD 任务：`ID1053051 添加模块面板添加目录组件`。
- 父需求：`【三级需求】【新版内容编辑器】新增目录组件`。

### 1.2 目标

- 在编辑器添加模块面板中新增“内容目录/目录组件”。
- 自动识别当前文章内容中的 `H1` 到 `H6` 标题，并生成目录结构。
- 支持目录层级、列表样式、文字样式、颜色、背景色、收起展开等配置。
- 前台支持点击目录跳转到对应章节，并支持带 hash 的 URL 访问后自动定位。
- 支持 PC、Pad、移动端展示；同一页面允许存在多个目录并同步当前阅读位置。

### 1.3 非目标与限制

- 目录保存为静态 HTML，前台页面不实时重新提取标题；每次进入编辑器编辑并保存后更新目录内容。
- 产品、文章、FAQ、下载、图册、列表等动态数据来源内容不纳入本次目录自动提取范围，需按 TAPD 描述排除。
- 区块本身不强制新增锚点；当目标区块已有锚点配置时，跳转后 URL 可按锚点变化；未配置锚点时通过 JS 滚动跳转，URL 不变化。

## 3. 组件入口与适用范围

### 3.1 添加入口

- 在编辑器添加模块面板中新增目录组件入口。
- 设计稿展示位置：添加模块面板的“网页组件”分组。
- 组件名称建议：`内容目录`。
- 默认图标：设计稿中为目录/节点连线样式图标，最终以设计资源为准。

### 3.2 适用内容

- 自动提取当前编辑内容中的静态标题标签：`H1`、`H2`、`H3`、`H4`、`H5`、`H6`。
- 目录项展示文本取标题标签的纯文本内容。
- 标题层级按文档中的真实标题标签层级生成，不应因勾选过滤而改变原始层级关系。

### 3.3 排除范围

以下内容不参与目录自动生成：

- 产品动态内容。
- 文章动态内容。
- FAQ 动态内容。
- 下载动态内容。
- 图册动态内容。
- 列表动态内容。

## 4. 功能需求

### 4.1 标题自动提取

- 目录组件添加后，自动扫描当前文章内的 `H1` 到 `H6` 标题。
- 仅展示用户在设置项中勾选的标题层级。
- 默认勾选 `H2`、`H3`。
- 当前内容中不存在某个标题层级时，该层级勾选项置灰，不允许勾选。
- 勾选层级变更后，编辑器画布中目录内容需要实时刷新。
- 若页面内容发生标题新增、删除、文案修改，目录内容在编辑器内应随编辑状态更新；最终前台内容以保存后的静态 HTML 为准。

### 4.2 目录静态保存

- 保存时将目录内容固化为静态 HTML。
- 前台访问页面时不重新扫描正文生成目录。
- 后续如果正文标题变化，需要再次进入编辑器更新并保存后，前台目录才会变化。

### 4.3 点击跳转

- 预览模式与前台页面中，点击目录项后滚动到对应章节。
- 编辑模式下目录文字不可作为普通文本选中编辑，避免误改目录项内容。
- 若目标区块已有锚点配置，跳转后可使用该锚点并更新 URL。
- 若目标区块没有锚点配置，通过 JS 滚动到对应位置，URL 保持不变。

### 4.4 Hash URL 访问

- 用户直接访问带 hash 的 URL 时，应自动滚动到对应章节。
- 示例：`https://www.tscastingparts.com/more-featured-zinc-cast-products/#Precision_Mold_Design`。
- 当 hash 对应已有锚点时，优先使用原有锚点定位。
- 当 hash 无法匹配任何章节或锚点时，页面保持默认加载位置，不应报错或阻断页面渲染。

### 4.5 多目录同步

- 同一页面允许存在多个目录组件。
- 多个目录组件应展示相同的当前阅读位置状态。
- 用户滚动页面时，所有目录组件中的当前章节状态需要同步。
- 用户点击任一目录组件中的目录项后，其他目录组件也应同步更新当前章节状态。
- 兼容网页中已有文章目录能力的场景，包括 3.0 与 4.0 文章目录。

### 4.6 收起展开

- 目录组件包含标题区域与箭头。
- 默认标题文案：`Table of Contents`。
- 标题文案支持翻译。
- PC 与 Pad 默认展开。
- 移动端默认收起。
- 点击标题区域或箭头后切换展开/收起状态。
- 箭头颜色与标题文字颜色保持一致，箭头大小与标题文字大小保持统一视觉规格。

## 5. 设置项需求

### 5.1 层级展示设置

- 支持 `H1` 到 `H6` 六个层级的勾选控制。
- 默认勾选 `H2`、`H3`。
- 当前页面没有对应层级标题时，该层级置灰。
- 勾选变更后实时更新目录预览。
- 每个目录组件可独立保存自己的层级勾选配置。

### 5.2 位置移动

- 选中目录组件后，工具栏支持上下移动。
- 上移、下移行为应遵循现有编辑器组件移动规则。

### 5.3 列表样式

- 支持三种列表样式：
  - 无列表。
  - 无序列表。
  - 有序列表。
- 默认展示“无列表”状态。
- 点击列表设置后可在三种状态之间切换。
- 有序列表需要按标题层级生成类似 `1.`、`2.1.`、`2.2.` 的层级编号。
- 无序列表的具体符号样式以最终设计稿或现有组件样式规范为准。

### 5.4 文字样式

- 支持加粗、斜体、下划线、文字样式、字号、行高等设置。
- 在设置项中修改文字样式时，应用范围为目录内所有文字。
- 目录内部文字不可被单独选中编辑。
- 文字层级规则：
  - 第一层级使用设置的字号。
  - 第二层级及更深层级默认比第一层级小 `2px`。
  - 示例：设置字号为 `16px` 时，第一层级为 `16px`，第二层级及更深层级为 `14px`。
- 加粗、斜体、下划线等文字装饰对所有层级统一生效。

### 5.5 文字颜色

- 支持修改目录文字颜色。
- 默认文字样式为链接文字样式。
- 文字颜色修改后应用于所有目录项文字与标题区域文字。

### 5.6 背景颜色

- 支持修改目录组件背景色。
- 默认背景色：`#F8F9FA`。
- 背景颜色修改范围为目录组件整体背景。

### 5.7 删除

- 选中目录组件后支持删除。
- 删除行为应删除整个目录组件。
- 删除后不影响正文标题内容与已有锚点配置。

## 6. 样式与响应式需求

### 6.1 默认视觉样式

- 默认文字样式使用链接文字样式。
- 默认标题文案为 `Table of Contents`。
- 默认背景色为 `#F8F9FA`。
- 标题最多展示一行，超出省略。
- 目录项在 PC 端最多展示一行，超出省略。
- 每行上下间距为 `10px`。
- 每级缩进为 `16px`。
- 目录最大高度为 `600px`，超出后内部滚动展示。

### 6.2 PC 端

- 默认展开目录内容。
- 展示标题区域、箭头与目录列表。
- 目录项按层级缩进展示。
- 长标题单行省略。
- 支持最大高度 `600px` 后内部滚动。

### 6.3 Pad 端

- 与 PC 端展示和交互保持一致。
- 具体宽度、间距、字体表现以设计稿为准。

### 6.4 移动端

- 默认收起，仅展示标题区域与箭头。
- 展开后展示目录列表。
- 移动端目录项超出 `2` 行后省略展示。
- 移动端展开后的缩进、间距、颜色与 PC 规则保持一致，但需适配移动端容器宽度。

## 7. 状态与边界场景

### 7.1 无标题内容

- 当当前内容中不存在 `H1` 到 `H6` 标题时，目录组件应展示空状态或仅展示标题区域。
- `H1` 到 `H6` 勾选项均应置灰。
- 不应生成无效跳转链接。

### 7.2 部分层级无标题

- 仅无标题的层级置灰。
- 已存在标题的层级可勾选。
- 默认勾选的 `H2`、`H3` 如果当前内容不存在，应置灰且不展示对应目录项。

### 7.3 超长标题

- PC 与 Pad：目录项最多展示一行，超出省略。
- 移动端：目录项最多展示两行，超出省略。
- 省略不影响点击跳转目标。

### 7.4 目录过高

- 目录最大高度为 `600px`。
- 超出高度后目录内部滚动，不应撑开页面布局。
- 滚动目录内部内容时，不应影响页面正文滚动定位逻辑。

### 7.5 加载中

- 编辑器后台生成或刷新目录时，需要有 loading 状态。
- loading 期间不应允许用户触发重复生成导致状态错乱。
- loading 失败时应保留上一次有效目录或展示可恢复的失败状态，避免组件空白不可操作。

### 7.6 锚点冲突

- 当多个标题文本相同导致生成相同 hash 标识时，需要保证跳转目标唯一。
- 建议采用稳定唯一标识作为内部跳转依据，标题文本仅作为展示内容。
- 如使用已有锚点，应优先遵循用户设置的锚点。

### 7.7 动态内容排除

- 动态数据区域中的标题不参与目录生成。
- 如果页面同时存在静态标题与动态标题，仅静态标题生成目录。
- 需人工确认动态模块在 DOM 中的识别方式，避免误提取。

## 8. 验收标准

### 8.1 添加与默认态

- 在添加模块面板的“网页组件”分组可看到“内容目录”。
- 点击或拖拽后可添加到画布。
- 新增后默认提取当前页面标题。
- 默认勾选 `H2`、`H3`。
- 默认列表样式为无列表。
- 默认背景色为 `#F8F9FA`。
- 默认标题文案为 `Table of Contents`。

### 8.2 设置项

- `H1` 到 `H6` 勾选项能根据正文标题存在情况正确启用或置灰。
- 勾选层级后，目录内容实时刷新。
- 列表样式可在无列表、无序列表、有序列表间切换。
- 文字样式、文字颜色、背景色修改后能即时预览并保存回显。
- 上移、下移、删除操作符合编辑器现有组件行为。

### 8.3 保存与回显

- 保存后再次打开编辑器，目录内容与配置正确回显。
- 前台页面展示保存时生成的静态目录。
- 修改正文标题后，未保存前前台目录不变化；编辑并保存后前台目录更新。

### 8.4 跳转体验

- 预览模式点击目录项可滚动到对应章节。
- 前台点击目录项可滚动到对应章节。
- 直接访问带 hash 的 URL 可自动定位对应章节。
- 无匹配 hash 时页面正常展示。

### 8.5 多端展示

- PC 默认展开，长标题单行省略。
- Pad 与 PC 一致。
- 移动端默认收起。
- 移动端展开后目录项超出两行省略。

### 8.6 多目录场景

- 同一页面添加两个及以上目录组件时均可正常显示。
- 滚动页面时多个目录的当前阅读位置状态同步。
- 点击任意目录项后，所有目录组件当前状态同步。

## 9. 测试场景建议

- 标题层级完整：页面同时包含 `H1` 到 `H6`，验证提取、层级缩进、层级勾选。
- 默认层级：仅包含 `H2`、`H3`，验证默认展示。
- 缺失默认层级：页面只有 `H1` 或 `H4`，验证 `H2`、`H3` 置灰与空目录表现。
- 超长标题：验证 PC 单行省略、移动端两行省略。
- 有序列表：验证多层级编号格式。
- 无序列表：验证列表符号与层级缩进。
- 样式设置：验证字体、字号、行高、加粗、斜体、下划线、文字颜色、背景色保存回显。
- 目录高度超出 `600px`：验证内部滚动。
- 点击跳转：验证预览模式、前台页面、无锚点 JS 跳转、已有锚点 URL 变化。
- Hash 访问：验证有效 hash、无效 hash、重复标题 hash。
- 多目录：验证两个目录同步当前阅读位置。
- 移动端默认收起：验证初始状态、展开状态、再次收起状态。
- 动态内容排除：验证产品、文章、FAQ、下载、图册、列表等动态标题不被提取。

## 10. 待确认事项

- “当前文章内容”的具体 DOM 范围需要确认：是当前页面全部静态内容，还是仅特定正文容器。
- 动态内容排除的技术识别规则需要确认：按组件类型、数据标识、容器 class，还是后端数据来源标记。
- 无标题时的空状态文案与视觉样式需要确认。
- 无序列表的符号样式需要确认。
- 当前阅读位置的高亮样式未在 TAPD 文本中明确，需要产品或设计补充。
- 移动端“默认收起”与设计稿 `移动端效果.png` 箭头方向存在歧义，需要确认箭头朝向与展开/收起状态的对应关系。
- 标题文案 `Table of Contents` 的翻译来源需要确认：是否接入现有 i18n 词条，以及是否允许用户自定义标题文案。
- 目录组件是否允许用户手动编辑标题文案，需要确认；当前文档按“标题字段支持翻译，目录项不可选中编辑”处理。
- 多目录同步是否需要兼容页面已有 3.0/4.0 文章目录的高亮状态和滚动监听机制，需要技术侧确认集成方式。
- loading 加载失败后的具体错误提示样式需要确认。

## 11. 实施风险提示

- 静态 HTML 保存策略会导致前台目录与正文标题存在时间差，测试时需要覆盖“正文改了但未保存目录”的情况。
- 重复标题、特殊字符标题、多语言标题可能影响 hash 生成与跳转稳定性，需要使用唯一标识兜底。
- 多目录同步会引入全局滚动监听，需要注意性能与重复监听清理。
- 移动端目录展开后内容较长，需避免目录内部滚动与页面滚动冲突。
- 动态内容排除如果仅靠 DOM 文本判断，容易误提取，需要依赖稳定组件类型或数据标识。
