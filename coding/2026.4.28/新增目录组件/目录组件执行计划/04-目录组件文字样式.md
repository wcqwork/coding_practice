# 04-目录组件支持加粗/斜体/下划线/文字样式/行高

## 需求范围

目录组件需要支持统一文字样式：

- 加粗。
- 斜体。
- 下划线。
- 文字样式。
- 字号。
- 行高。
- 设置项修改后应用范围为目录组件内所有文字。
- 目录里面的文字不可被单独选中编辑。
- 文字层级规则：第一层级使用设置字号，第二层级及更深层级默认比第一层级小 `2px`。
- 加粗、斜体、下划线对所有层级统一生效。

本任务只规划文字样式，不处理文字颜色/背景颜色，颜色在任务 05 处理。

## 当前代码依据

- 通用文字格式能力：`phoenix-ai-generate-products/src/components/FloatingBubbleMenu/composables/useTextFormatting.js`
- 文字按钮：`phoenix-ai-generate-products/src/components/FloatingBubbleMenu/toolbars/TextMarkButtons/TextMarkButtons.vue`
- 字号下拉：`phoenix-ai-generate-products/src/components/FloatingBubbleMenu/toolbars/FontSizeDropdown/FontSizeDropdown.vue`
- 行高下拉：`phoenix-ai-generate-products/src/components/FloatingBubbleMenu/toolbars/LineHeightDropdown/LineHeightDropdown.vue`
- 字体样式全局数据：`getCyberPhoenixFun()` 在 `FloatingBubbleMenu.vue` 中提供 `fontTypographyTypeList`
- 目录工具栏建议：`phoenix-ai-generate-products/src/components/FloatingBubbleMenu/toolbars/TableOfContentsToolbar/TableOfContentsToolbar.vue`
- 目录渲染建议：`phoenix-ai-generate-products/src/components/tiptap-extensions/TableOfContents/TableOfContentsView.vue`

## 实现原则

目录组件是 atom Node，内部文字不可作为普通正文选区处理。因此不能直接复用 `toggleBold()`、`setMark('textStyle')` 这类针对选区的 Tiptap mark 命令。需要将样式保存为目录组件 attrs，再由目录组件渲染层统一应用。

通用工具栏组件可以复用 UI 或交互样式，但命令执行必须改成更新 `tableOfContents` Node attrs。

## 数据结构建议

在目录组件 attrs 中新增：

```js
{
  bold: false,
  italic: false,
  underline: false,
  fontSize: '',
  lineHeight: '1.7',
  fontClass: '',
  fontStyleName: ''
}
```

说明：

- `fontSize` 建议保存带单位的字符串，如 `16px`；为空时继承默认链接文字样式字号，不在目录组件里硬编码默认字号。
- `lineHeight` 沿用现有编辑器选项，如 `1.7`。
- `fontClass` 用于保存全局字体样式 class，参考 `useTextFormatting.js` 中 `GLOBAL_CLASS_PREFIX` 处理方式。
- `fontStyleName` 可选，仅用于回显；真正渲染以 `fontClass` 为准。

渲染时派生：

- 第一层级字号：优先使用 `fontSize`；为空时继承链接文字默认字号。
- 第二层级及更深层级字号：当第一层级能解析为 px 时使用 `max(fontSize - 2px, 6px)`；继承默认字号或非 px 单位时，通过 CSS 变量/计算值按视觉稿兜底。
- 如果 `fontSize` 不是 px 值，无法计算 `-2px` 时，所有层级使用同一字号，并记录为风险。

## 实施步骤

1. 扩展 Node attrs。
   - 在 `TableOfContents/index.js` 的 `addAttributes` 中声明文字样式属性。
   - `parseHTML` 从 `data-bold`、`data-italic`、`data-underline`、`data-font-size`、`data-line-height`、`data-font-class` 读取。
   - `renderHTML` 输出对应 `data-*`，确保保存回显。

2. 建立目录样式更新工具。
   - 在 `tableOfContentsUtils.js` 中实现 `updateCurrentTocAttrs(editor, patch)`。
   - 统一处理当前选中目录组件的位置、attrs 合并、`setNodeMarkup`。
   - 避免工具栏各按钮重复写 ProseMirror 更新逻辑。

3. 实现目录工具栏文字按钮。
   - `bold`、`italic`、`underline` 使用按钮开关态。
   - 点击后更新当前目录组件 attrs，不调用正文 mark 命令。
   - 回显状态直接读取当前 Node attrs。

4. 实现字号设置。
   - 可复用 `FontSizeDropdown` 的 UI，或抽出一个可传入 getter/setter 的通用组件。
   - 如果复用成本过高，先在 `TableOfContentsToolbar` 内实现目录专用字号下拉，保持视觉一致。
   - 选择字号后更新 `fontSize`。
   - 目录项第二层级及以后在 View 层派生 `font-size: calc(...)` 或直接计算 px。

5. 实现行高设置。
   - 沿用现有 `lineHeightOptions`：`1`、`1.2`、`1.3`、`1.4`、`1.5`、`1.6`、`1.7`、`1.8`、`1.9`、`2.0` 等。
   - 更新 attrs 中的 `lineHeight`。
   - 应用于标题区域和目录项所有文字，若设计要求标题与目录项分别设置，再扩展属性。

6. 实现文字样式。
   - 从 `fontTypographyTypeList` 读取可选样式。
   - 选择后保存 `fontClass`。
   - 如果选择自定义字号，应按现有逻辑清除 `fontClass`，避免字体样式和字号互相冲突。
   - 如果文字样式包含字号，应明确是否覆盖 `fontSize`；建议保留现有编辑器规则：选择全局样式时清理自定义字号，选择字号时清理全局样式。

7. View 层统一应用。
   - 外层增加 class：`toc-is-bold`、`toc-is-italic`、`toc-is-underline` 或直接 style。
   - 标题文字、箭头、目录项均继承这些样式。
   - 对每个目录项根据 `depth` 计算字号。
   - 不给目录项设置 `contenteditable`，避免内部选区。

8. 工具栏可见性。
   - `useToolbarCore.js` 中 `tableOfContents` 属于 `atomic` 与 `nonConvert`。
   - `FloatingBubbleMenu.vue` 对目录组件展示专用工具栏，不展示正文文本工具栏，避免用户误以为可以选中目录内部部分文字。

## 验收标准

- 选中目录组件后可设置加粗、斜体、下划线。
- 设置加粗/斜体/下划线后，标题区域与所有目录项统一生效。
- 可设置字号，第一层级使用所选字号，第二层级及更深层级比第一层级小 `2px`。
- 未设置字号时，目录文字继承默认链接文字样式字号，不额外写死 `16px`。
- 可设置行高，目录标题和目录项间距视觉稳定，不出现行内裁切。
- 可选择文字样式并保存回显。
- 目录内部文字不能被单独选中修改。
- 保存 HTML 后重新打开，文字样式正确回显。

## 风险与依赖

- 现有 `FontSizeDropdown`、`LineHeightDropdown` 依赖 `provide('textFormatting')` 和选区命令，直接复用可能会误操作正文，需要谨慎抽象。
- 如果全局文字样式 class 来自宿主注入 CSS，编辑器 iframe 和前台都必须加载同一套 CSS，否则保存后前台样式可能不一致。
- `fontSize - 2px` 只适用于 px 单位；非 px 单位需要产品确认换算方式。
