# 01-添加模块面板添加目录组件

## 需求范围

在编辑器添加模块面板中新增“内容目录”组件入口。根据设计稿 `新增.png`，入口位于 Slash 添加菜单的“网页组件”分组，图标为目录/节点连线样式。点击入口后在正文中插入一个目录组件，组件默认展示标题文案 `Table of Contents`、默认背景色 `#F8F9FA`、默认展示 H2/H3 标题、默认列表样式为“无列表”。

本任务只负责入口、组件 Node 骨架和基础注册，不实现完整设置项、跳转、静态保存细节。后续任务在此基础上继续补齐。

## Node 基础属性建议

目录组件建议作为块级自定义 Node，实现为可整体选中、内部文字不可直接编辑的组件：

```js
{
  name: 'tableOfContents',
  group: 'block',
  atom: true,
  selectable: true,
  draggable: false
}
```

首批 attrs：

- `title`：标题文案，默认取 i18n 的 `Table of Contents`，后续设置项可修改。
- `levels`：展示层级数组，默认 `[2, 3]`。
- `listStyle`：`none | bullet | ordered`，默认 `none`。
- `items`：保存后的目录静态快照数组，初始为空，插入后由标题提取逻辑填充。
- `backgroundColor`：默认 `#F8F9FA`。
- `textColor`：默认链接色，建议初始为空，渲染时使用 CSS 变量/链接样式兜底。
- `fontSize`、`lineHeight`、`bold`、`italic`、`underline`、`fontClass`：后续文字样式任务使用。
- `collapsedMobile`：移动端默认收起，建议默认 `true`。

HTML 序列化建议：

- 外层使用 `div[data-table-of-contents]` 作为识别标记。
- 所有配置用 `data-*` 或 JSON 字符串保存，避免重开编辑器丢失。
- `items` 如果体积较大，优先用 `data-toc-items` 保存 JSON 字符串，并在 `parseHTML` 中容错解析。

## 实施步骤

1. 新建 `TableOfContents` Tiptap Node。
   - 实现 `addAttributes`、`parseHTML`、`renderHTML`。
   - 插入初始 attrs：`title`、`levels`、`listStyle`、`items`、基础样式属性。
   - `renderHTML` 输出稳定结构，保证源码模式下可见且可被再次解析。

2. 新建 `TableOfContentsView.vue`。
   - 负责编辑器内预览。
   - 外层 `contenteditable="false"`，避免目录项文字被当普通正文编辑。
   - 渲染标题区域、箭头占位、目录列表容器。
   - 暂时只展示 `items`，无标题时显示标题区域和空列表/空态占位，完整空态在任务 02 细化。

3. 在 `useEditorCreate.js` 注册扩展。
   - import `TableOfContents`。
   - 加入 `extensions` 数组，位置建议放在其它自定义 block 之后、`SlashCommands` 之前，便于 Slash 插入时 schema 已存在。

4. 在 `SlashCommands.js` 增加网页组件入口。
   - `group: 'web'`
   - `title: t('slashMenu.items.tableOfContents.title')`
   - `description: t('slashMenu.items.tableOfContents.desc')`
   - `icon: getSlashIcon('tableOfContents')`
   - `command` 使用 `insertContent({ type: 'tableOfContents', attrs: defaultAttrs })`
   - 默认插入时调用一次标题提取工具，填充初始 `items`。

5. 增加图标。
   - 新增 `tableOfContents.svg`。
   - 在 `SlashIcons.js` import 并加入 `icons` 映射。

6. 增加 i18n。
   - `slashMenu.items.tableOfContents.title`：简中建议“内容目录”。
   - `slashMenu.items.tableOfContents.desc`：建议“自动提取标题生成目录”。
   - `editor.tableOfContents.titleDefault`：`Table of Contents`。
   - `editor.tableOfContents.*` 后续设置项文案预留。

7. 接入气泡工具栏基础能力。
   - 在 `useToolbarCore.js` 的 `BLOCKS.atomic`、`nonConvert`、`alignDisallowed`、`deleteAllowed` 加入 `tableOfContents`。
   - 在 `FloatingBubbleMenu.vue` 为 `editor?.isActive('tableOfContents')` 预留 `TableOfContentsToolbar`。
   - 先接入移动、删除能力；复杂设置在后续任务补充。

8. 确认属性保留。
   - `PreserveAttrs.js` 会从 schema 收集已知 attrs，新 Node 的 attrs 需要完整声明。
   - 未声明但前台需要保留的 `data-*` 不应依赖 `preservedAttrs`，优先在 Node attrs 中显式建模。

## 验收标准

- 在 Slash 菜单“网页组件”分组中可看到“内容目录”入口，位置符合设计稿。
- 点击入口后正文插入目录组件，不报 schema 错误。
- 目录组件可整体选中，内部文字不可作为普通文本编辑。
- 选中目录组件后出现基础气泡工具栏，支持上移、下移、删除。
- 保存 HTML 后重新打开编辑器，目录组件仍能解析回 `tableOfContents` Node。
- 中英文/繁体环境下入口文案不出现 key 名兜底。

## 风险与依赖

- 入口是否受 `newEditorAuth` 权限控制需产品确认；当前建议不复用“区块”权限，目录是基础网页组件。
- 若后续要求支持拖拽添加，需要检查 Slash 菜单现有实现是否支持卡片拖拽；当前需求只明确添加入口。
- 如果 `items` 直接放入 `data-*`，标题较多时 HTML 体积会增大，任务 08 需要再评估静态快照格式。
