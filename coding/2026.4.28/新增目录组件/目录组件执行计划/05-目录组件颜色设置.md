# 05-目录组件支持文字颜色、背景颜色

## 需求范围

目录组件需要支持：

- 修改文字颜色，应用所有文字。
- 修改背景颜色，应用目录组件整体背景。
- 背景颜色默认 `#F8F9FA`。
- 默认文字样式为链接文字样式。
- 标题区域文字、箭头、目录项文字、列表编号/符号默认跟随文字颜色。

本任务只处理颜色属性、颜色设置 UI 和保存回显。文字加粗、字号、行高在任务 04；样式布局和响应式在任务 06。

## 当前代码依据

- 文字颜色按钮：`phoenix-ai-generate-products/src/components/FloatingBubbleMenu/toolbars/TextColorPickerBtn/TextColorPickerBtn.vue`
- 背景颜色按钮：`phoenix-ai-generate-products/src/components/FloatingBubbleMenu/toolbars/BgColorPickerBtn/BgColorPickerBtn.vue`
- 颜色读取/设置逻辑：`phoenix-ai-generate-products/src/components/FloatingBubbleMenu/composables/useTextFormatting.js`
- 颜色预设来源：`getCyberPhoenixFun()` 在 `FloatingBubbleMenu.vue` 中提供 `colorMatching`
- 目录工具栏建议：`phoenix-ai-generate-products/src/components/FloatingBubbleMenu/toolbars/TableOfContentsToolbar/TableOfContentsToolbar.vue`
- 目录渲染建议：`phoenix-ai-generate-products/src/components/tiptap-extensions/TableOfContents/TableOfContentsView.vue`

## 实现原则

目录组件是自定义 atom Node，颜色不能通过正文 mark 的 `setColor` 或 `setHighlight` 修改。需要保存为目录组件 attrs，并由 View/HTML 渲染统一应用。

颜色选择器 UI 可以复用现有组件的弹层、预设色与取色能力，但命令执行必须走目录组件 attrs 更新。

## 数据结构建议

在目录组件 attrs 中新增：

```js
{
  textColor: '',
  backgroundColor: '#F8F9FA'
}
```

说明：

- `textColor` 为空时使用链接文字默认样式，避免写死蓝色；渲染层可用 CSS 变量兜底，例如 `var(--rt-link-color, #1688ff)`。
- `backgroundColor` 必须有默认值 `#F8F9FA`。
- 不建议把标题颜色和目录项颜色拆开，需求明确应用所有文字。

HTML 序列化：

- `data-text-color`
- `data-background-color`
- 外层 style 可输出 `background-color`，但配置仍以 `data-*` 为准，方便 parseHTML 回填。

## 实施步骤

1. 扩展 Node attrs。
   - 在 `TableOfContents/index.js` 中声明 `textColor`、`backgroundColor`。
   - `parseHTML` 优先读取 `data-text-color`、`data-background-color`。
   - 兼容读取内联 style 的 `color`、`background-color` 作为兜底。
   - `renderHTML` 输出 `data-*` 和必要内联样式。

2. 抽象目录颜色更新方法。
   - 在 `tableOfContentsUtils.js` 中复用 `updateCurrentTocAttrs(editor, patch)`。
   - `setTocTextColor(editor, color)` 更新 `textColor`。
   - `setTocBackgroundColor(editor, color)` 更新 `backgroundColor`。
   - 清空文字颜色时将 `textColor` 设置为空字符串，回到链接默认样式。
   - 清空背景颜色时回到 `#F8F9FA`，不要置空。

3. 实现工具栏颜色入口。
   - `TableOfContentsToolbar.vue` 中展示文字颜色按钮和背景颜色按钮。
   - 优先复用现有颜色按钮的视觉表现；如果现有组件强绑定 `textFormatting`，则抽出通用颜色面板组件，或新增目录专用按钮。
   - 颜色面板使用 `colorMatching` 预设，保持与编辑器其它文字颜色一致。

4. 颜色回显。
   - 文字颜色按钮读取当前目录 Node 的 `textColor`；为空时显示默认/链接色状态。
   - 背景颜色按钮读取 `backgroundColor`，默认显示 `#F8F9FA`。
   - 选中不同目录组件时，颜色按钮状态切换到对应组件 attrs。

5. View 层应用。
   - 外层设置 `backgroundColor`。
   - 标题文字、箭头、目录项文字、编号、无序 marker 使用 `color: resolvedTextColor`。
   - 如果 `textColor` 为空，使用链接默认 class 或 CSS 变量，而不是写死内联色。
   - hover/active 状态默认也跟随文字色；当前阅读位置高亮如需特殊色，任务 07/06 再定义。

6. 静态 HTML 输出。
   - `renderHTML` 输出的结构必须包含颜色样式，前台没有 Vue NodeView 时仍能按保存的 HTML 展示。
   - 如果前台需要额外 CSS class，任务 08 统一收敛到静态样式注入或内联样式。

7. i18n 文案。
   - `editor.tableOfContents.textColorTitle`：文字颜色。
   - `editor.tableOfContents.backgroundColorTitle`：背景颜色。
   - `editor.tableOfContents.resetTextColor`：恢复默认文字颜色。
   - `editor.tableOfContents.resetBackgroundColor`：恢复默认背景。

## 验收标准

- 新增目录组件默认背景为 `#F8F9FA`。
- 默认文字视觉与链接文字样式一致。
- 修改文字颜色后，标题、箭头、目录项、编号/符号统一变化。
- 修改背景颜色后，仅目录组件整体背景变化，不影响正文其它内容。
- 清除文字颜色后恢复默认链接文字样式。
- 清除背景颜色后恢复 `#F8F9FA`。
- 多个目录组件可分别保存不同文字色和背景色。
- 保存 HTML 后重新打开，颜色正确回显。

## 风险与依赖

- 现有 `TextColorPickerBtn`、`BgColorPickerBtn` 通过 `provide('textFormatting')` 操作选区，直接复用可能会改到正文，需要先解耦 UI 与命令。
- 默认“链接文字样式”的具体颜色可能来自宿主主题或全局 CSS，不能只按设计稿写死蓝色。
- 如果前台缺少编辑器 CSS 变量，需要在静态 HTML 中提供兜底颜色。
